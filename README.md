# 个人工作台

一个运行在本机的个人效率工作台，采用左侧导航、右侧内容区的简约控制台布局。它把高频使用的提示词、网址、API Key 和本机软件快捷方式集中到一个 `127.0.0.1` 页面中。

当前版本：`v1.0`

> 重要：本项目是本地优先应用，不提供账户、云同步或远程数据库。提示词、网址和 API Key 数据保存在当前浏览器的 `localStorage`；应用快捷方式文件保存在项目目录的 `.workbench-data`。请自行备份重要数据。

## 快速开始

### 环境要求

- Windows（应用启动器只支持 Windows）。
- Node.js 20.19+，或 Node.js 22.12+。
- 可用的现代浏览器，且浏览器允许当前页面使用 `localStorage`、Web Crypto 和剪贴板功能。

### 安装和启动

在项目根目录执行：

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

然后打开：<http://127.0.0.1:5173/>

开发服务需要保持运行。应用启动器的本机接口由 Vite 开发/预览服务提供，直接双击 `index.html` 无法使用该功能。

### 构建检查

```powershell
npm run build
```

构建产物在 `dist/`，该目录已被 Git 忽略。生产预览可以执行：

```powershell
npm run preview -- --host 127.0.0.1
```

## 第一次使用

第一次打开页面时，需要设置一个至少 8 位的工作台密码。以后刷新页面或重新打开页面，都需要输入密码解锁。

密码本身不会写入浏览器。当前版本没有密码找回或重置流程：忘记密码后，原有 API Key 无法解密；清除当前站点数据后可以重新初始化，但会同时清除该浏览器保存的提示词、网址和 API Key 数据。

## 功能和使用方法

### 概述

打开工作台后默认进入“概述”。左侧导航分为“工作台”“资源中心”和“工具”，右侧显示当前模块内容。侧边栏底部的“设置”按钮目前保留为入口和占位页，点击后会显示后续模块提示。

概述页提供提示词库、应用启动器和网址收藏的快捷入口，并显示最近使用的提示词。当前日期文案是界面展示内容，不代表系统时间同步逻辑。

### 提示词库

1. 点击左侧“提示词库”。
2. 点击“新建提示词”，填写标题和内容；在标签输入框中输入内容后按 `Enter` 或逗号添加标签。
3. 保存后，可以通过搜索框匹配标题、内容和标签，也可以点击标签筛选。
4. 每张提示词卡片右上角的三点菜单包含“复制”“编辑”“删除”。复制只复制提示词内容。
5. 每页显示 6 条记录。记录超过 6 条后，底部会显示上一页、页码和下一页。

首次使用时，内置 24 条示例提示词；已有浏览器数据会保留，并按标题补齐缺少的示例数据。

### 网址收藏

1. 点击左侧“网址收藏”，再点击“新建网址”。
2. 填写标题、网址、备注和标签。网址必须以 `http://` 或 `https://` 开头。
3. 每条记录可以直接打开、编辑或删除。
4. 每页显示 6 条记录，超过 6 条后显示分页。

首次使用时会提供 20 条“分页测试网址”，它们会与已有收藏按标题合并，不会覆盖同名的本地记录。这些地址使用 `example.com`，主要用于检查分页布局。

### API Keys

点击左侧“API Keys”，每条记录包含以下字段：

| 字段 | 存储方式 | 使用说明 |
| --- | --- | --- |
| 名称 | 明文 | 用于识别记录，例如 `OpenAI Production` |
| 服务商 | 明文 | 例如 OpenAI、Anthropic 或自建服务 |
| API Key | AES-256-GCM 密文 | 保存时加密，列表默认掩码 |
| 请求地址 | 明文 | 必须是 `http://` 或 `https://` 地址 |

使用步骤：

1. 点击“添加 API Key”，填写四个字段并点击“加密保存”。
2. 列表中点击眼睛按钮，可以在当前已解锁页面中显示或隐藏 API Key。
3. 编辑记录时，页面会在内存中解密原 Key；重新保存时会使用新的随机 IV 重新加密。
4. 每页显示 6 条记录，超过 6 条后显示分页。

只有 API Key 字段加密，名称、服务商和请求地址按设计以明文保存，便于列表展示和识别。

### 个人书库和阅读器

个人书库用于导入并阅读本机电子书，不是阅读状态记录工具。

1. 点击左侧“个人书库”，点击右上角“导入书籍”。
2. 选择本机的 `PDF`、`EPUB`、`TXT`、`Markdown` 或 `HTML` 文件。
3. 文件会保存到当前浏览器的 IndexedDB，不会上传网络；书库保存书名、文件名、类型、大小、可选的作者/分类信息和上次阅读位置。
4. 点击书籍卡片上的“阅读”进入右侧主内容区的阅读页。左上角“返回书库”返回列表；PDF 使用浏览器内置预览，EPUB 使用内置分页阅读器，TXT/Markdown 使用本地文本阅读视图，HTML 使用沙箱 iframe 阅读。
5. EPUB 阅读页底部提供“上一页”和“下一页”按钮；每次翻页会保存当前 CFI，重新打开时直接恢复到上次页面。TXT/Markdown 会保存滚动位置，PDF/HTML 使用浏览器阅读视图。当前版本不计算或显示阅读百分比。
6. 可搜索书名、作者、分类和文件名，也可以按文件类型筛选。
7. 可以编辑书名、作者和分类；删除书籍会同时删除浏览器中的本地文件副本。
8. 每页显示 6 本书，超过 6 本后显示分页。

当前版本不支持直接导入 `.mobi`、`.azw` 等格式；请先转换为 PDF 或 EPUB。浏览器站点数据被清除后，导入的书籍文件也会随 IndexedDB 一并丢失。

### 应用启动器

应用启动器用于启动本机软件，不会启动远程程序：

1. 确认已经通过 `npm run dev` 或 `npm run preview` 启动本地服务。
2. 点击左侧“应用启动器”，点击“选择快捷方式”。
3. 在文件选择器中选择 Windows `.lnk` 或 `.url` 文件。每次选择一个，导入后会复制到项目的本地数据目录。
4. 点击单条记录的“启动”，或点击页面右上角“全部启动”并行启动所有已添加的快捷方式。
5. 可使用刷新按钮重新读取列表，也可以删除不再使用的快捷方式。

快捷方式启动由 Vite 本地接口调用 PowerShell `Start-Process -FilePath` 执行。服务会等待 PowerShell 子进程返回；如果快捷方式不存在、文件类型不支持或 Windows 启动失败，页面会显示错误。当前功能仅支持 Windows，浏览器本身不能直接执行本地文件。

## 本地安全模型

工作台密码用于派生 API Key 加密密钥，密码本身不会保存：

1. 首次设置密码时生成 16 字节随机盐值，并生成密码验证材料。
2. 使用 PBKDF2-SHA-256、250,000 次迭代派生 256 位密钥材料。
3. 每个 API Key 使用独立的 12 字节随机 IV，通过 AES-256-GCM 加密。
4. 浏览器只保存 API Key 的密文、IV、名称、服务商、请求地址和更新时间。
5. 解密后的 API Key 只存在当前页面内存中；刷新页面后必须重新解锁，已显示的值也会清除。

这适合本机个人使用，但不能替代操作系统凭据保险库。若设备已被恶意软件控制、浏览器被完全接管或工作台密码泄露，敏感数据仍可能暴露。

## 数据位置和备份

### 浏览器 `localStorage`

| 键名 | 内容 |
| --- | --- |
| `workbench-password` | 密码验证材料和盐值，不包含密码明文 |
| `workbench-prompts` | 提示词记录 |
| `workbench-links` | 网址收藏记录 |
| `workbench-books` | 个人书库元数据，不包含书籍文件本体 |
| `workbench-api-keys` | API Key 密文、IV 和非敏感元数据 |

这些数据跟随浏览器的来源（协议、主机和端口）。更换浏览器、端口或清除站点数据，都可能导致看不到原来的记录。

### 项目目录

| 路径 | 内容 |
| --- | --- |
| `.workbench-data/shortcuts.json` | 快捷方式名称、扩展名、文件名和本地索引 |
| `.workbench-data/shortcuts/` | 导入的 `.lnk` / `.url` 文件副本 |

`.workbench-data/` 已加入 `.gitignore`，不会被默认提交到 Git。需要备份应用启动器时，请单独备份该目录；不要把包含敏感信息的浏览器存储或导出的密文随意上传。

个人书籍文件不在项目目录中，而是保存在当前浏览器来源的 IndexedDB 数据库 `workbench-books-files` 中。

## 项目结构

```text
cc_workbench/
├── src/
│   ├── main.jsx       # React 状态、页面模块、表单和加密逻辑
│   └── styles.css     # 控制台布局、分页、响应式和状态样式
├── vite.config.js     # Vite 配置、本机快捷方式接口和 Windows 启动桥接
├── index.html         # 页面入口
├── package.json       # 脚本和依赖
├── package-lock.json  # npm 依赖锁定文件
├── README.md          # 功能和使用说明
└── HANDOFF.md         # 面向后续开发会话的交接文档
```

## 已实现和未实现范围

已实现：

- 简约控制台骨架、左侧导航、概述页和底部设置入口。
- 提示词标题、内容、标签、搜索、筛选、复制、编辑、删除和分页。
- 网址标题、网址、备注、标签、打开、编辑、删除和分页。
- API Key 的名称、服务商、API Key、请求地址、加密保存、显示/隐藏、编辑、删除和分页。
- 个人书库的本地 PDF/EPUB/TXT/Markdown/HTML 导入、浏览器本地保存、搜索、类型筛选、编辑、删除、分页和阅读器。
- EPUB 翻页位置和 TXT/Markdown 滚动位置会保存到本机书库元数据，重新打开书籍时自动恢复。
- 首次密码设置、刷新解锁、PBKDF2 密钥派生和 AES-256-GCM API Key 加密。
- Windows `.lnk` / `.url` 快捷方式导入、单个启动、全部启动和删除。
- 24 条提示词示例和 20 条网址分页测试数据。

暂未实现：

- 设置页的主题、默认页面和快捷键配置，目前是占位页。
- 数据导入导出、跨浏览器迁移、云同步和账户体系。
- 除 Windows 以外平台的应用启动器。
- `.mobi`、`.azw` 等电子书格式的直接导入。
