# 提示词库使用指南

## 功能概述

提示词库是一个本地化的 AI 提示词管理工具，支持标题、内容、标签的结构化存储，提供搜索、筛选、复制、编辑和删除功能。所有数据按工作区隔离存储，不会上传到云端。

---

## 快速开始

### 第一次使用

首次打开提示词库时，系统会自动加载 24 条示例提示词，涵盖常见的使用场景：

- **文案创作**：广告文案、社交媒体、产品描述
- **代码开发**：代码审查、Bug 修复、API 文档
- **数据分析**：数据清洗、可视化建议、统计分析
- **学习教育**：概念解释、学习计划、知识测试
- **日常办公**：邮件撰写、会议纪要、报告总结

这些示例可以直接使用，也可以根据需要修改或删除。

## 核心功能

### 1. 创建提示词

**操作步骤：**

1. 点击页面右上角的"**新建提示词**"按钮
2. 填写以下字段：
   - **标题**（必填）：简短描述提示词用途，例如"产品文案生成器"
   - **内容**（必填）：完整的提示词文本，支持换行和长文本
   - **标签**（可选）：输入标签后按 `Enter` 或输入逗号添加，用于分类和筛选
3. 点击"**保存**"完成创建

**标签使用技巧：**
- 按用途分类：`文案`、`代码`、`分析`、`翻译`
- 按场景分类：`工作`、`学习`、`创作`
- 按模型分类：`GPT-4`、`Claude`、`通用`
- 按语言分类：`中文`、`英文`、`日语`

---

### 2. 搜索提示词

**搜索范围：**
- 提示词**标题**
- 提示词**内容**
- 提示词**标签**

**使用方法：**
1. 在页面顶部搜索框输入关键词
2. 系统会实时过滤匹配的提示词
3. 搜索不区分大小写
4. 清空搜索框显示全部提示词

**搜索示例：**
```
输入：代码        → 匹配所有包含"代码"的提示词
输入：广告 文案   → 匹配包含"广告"或"文案"的提示词
输入：Bug         → 匹配包含"Bug"或"bug"的提示词
```

---

### 3. 标签筛选

**使用方法：**
1. 点击搜索框右侧的标签按钮
2. 系统会显示当前所有已使用的标签
3. 点击任意标签，筛选带有该标签的提示词
4. 再次点击取消筛选

**标签特性：**
- 自动统计：只显示当前工作区中实际使用的标签
- 动态更新：添加或删除提示词后，标签列表自动刷新
- 单选筛选：每次只能选择一个标签

---

### 4. 使用提示词

**复制内容：**
1. 找到需要的提示词卡片
2. 点击卡片右上角的"**⋯**"（更多）按钮
3. 选择"**复制**"
4. 系统会复制提示词**内容**到剪贴板（不包含标题和标签）
5. 页面底部会显示"已复制到剪贴板"提示

**最佳实践：**
- 复制后粘贴到 ChatGPT、Claude 或其他 AI 工具
- 根据具体需求修改提示词中的占位符
- 保存常用的修改版本为新提示词

---

### 5. 编辑提示词

**操作步骤：**
1. 点击提示词卡片右上角的"**⋯**"按钮
2. 选择"**编辑**"
3. 修改标题、内容或标签
4. 点击"**保存**"应用修改

**编辑场景：**
- 优化提示词措辞
- 添加或删除标签
- 更新示例或参数
- 修正错别字

---

### 6. 删除提示词

**操作步骤：**
1. 点击提示词卡片右上角的"**⋯**"按钮
2. 选择"**删除**"
3. 系统会立即删除该提示词（**不可恢复**）

⚠️ **注意**：删除操作无法撤销，请谨慎操作。如果不确定是否需要，可以先编辑标签为"待删除"，稍后再决定。

## 分页浏览

- 每页显示 **6 条**提示词
- 超过 6 条时，底部显示分页控制：
  - **◀ 上一页**：跳转到前一页
  - **页码按钮**：直接跳转到指定页
  - **下一页 ▶**：跳转到下一页
- 当前页码会高亮显示
- 搜索或筛选后会重置到第一页

## 使用场景

### 场景 1：AI 对话辅助
**需求**：使用 ChatGPT 或 Claude 进行专业对话
**方案**：
1. 在提示词库中创建不同角色的提示词
2. 例如："扮演 Python 专家"、"扮演产品经理"
3. 需要时快速复制对应提示词
4. 粘贴到 AI 工具开始对话

### 场景 2：内容创作模板
**需求**：批量生成相似格式的内容
**方案**：
1. 创建带占位符的提示词模板
2. 例如："为 [产品名称] 写一段 [风格] 的文案"
3. 复制后替换占位符
4. 快速生成多个变体

### 场景 3：代码审查清单
**需求**：确保代码审查覆盖所有要点
**方案**：
1. 创建代码审查提示词，包含检查项
2. 标签设为"代码"、"审查"
3. 每次审查时复制提示词
4. 逐项检查代码质量

### 场景 4：多语言翻译规范
**需求**：保持翻译风格一致
**方案**：
1. 为不同语言对创建翻译提示词
2. 明确语气、术语和格式要求
3. 标签设为"翻译"、"中英"、"中日"等
4. 翻译时使用对应提示词

## 数据管理

### 存储位置
- 提示词数据保存在 `.workbench-data/workbench.json`
- 按工作区隔离，每个工作区有独立的提示词库
- 不依赖浏览器 `localStorage`，修改端口不影响数据

### 导出与备份
**导出工作区配置：**
1. 进入"**设置 > 数据管理**"
2. 点击"**导出工作区配置**"
3. 系统会生成加密的 JSON 文件
4. 提示词库数据包含在导出文件中

**备份建议：**
- 定期备份 `.workbench-data/` 目录
- 导出工作区配置到云盘或移动硬盘
- 升级版本前先备份数据

### 导入配置
**场景**：迁移到新设备或恢复备份

**操作步骤：**
1. 在新设备的创建工作区页面选择"**导入已有配置**"
2. 或在已有工作区的"**设置 > 数据管理**"选择"**导入配置**"
3. 上传之前导出的 JSON 文件
4. 输入原工作区密码
5. 提示词库会自动恢复

## 多语言支持

提示词库界面支持三种语言：
- 🇨🇳 **中文（简体）**
- 🇺🇸 **English**
- 🇯🇵 **日本語**

**切换方法：**
1. 进入"**设置 > 语言**"
2. 选择目标语言
3. 界面标签自动更新
4. 提示词**内容**不会被翻译（保持原样）

## 最佳实践

### 1. 命名规范
**好的标题示例：**
- ✅ "产品文案生成器 - 科技风格"
- ✅ "Python 代码审查清单"
- ✅ "会议纪要总结模板"

**不好的标题示例：**
- ❌ "提示词1"
- ❌ "test"
- ❌ "aaa"

### 2. 标签策略
**推荐标签体系：**
```
用途维度：文案、代码、分析、翻译、学习、办公
场景维度：工作、个人、创作、研究
技术维度：Python、JavaScript、SQL、API
语言维度：中文、英文、日语
```

**标签使用原则：**
- 每个提示词 2-4 个标签
- 标签简洁（2-4 个字）
- 避免重复含义的标签

### 3. 内容组织
**提示词模板结构：**
```
角色设定：你是一个 [专业领域] 专家
任务描述：请帮我 [具体任务]
输出要求：
- 格式：[格式要求]
- 长度：[长度限制]
- 风格：[风格要求]
示例：[可选示例]
```

### 4. 版本管理
**建议**：
- 重要提示词修改前先复制一份
- 在标题后加版本号，如"产品文案 v2"
- 旧版本标签改为"已归档"

## 常见问题

### Q1: 示例提示词会被覆盖吗？
**A**: 不会。系统按**标题**合并示例数据：
- 如果标题不存在，添加示例
- 如果标题已存在，保留你的版本
- 不会删除你创建的提示词

### Q2: 可以跨工作区共享提示词吗？
**A**: 不能直接共享，但可以通过以下方式：
1. 导出源工作区配置
2. 在目标工作区导入
3. 或手动复制粘贴提示词内容

### Q3: 提示词数量有限制吗？
**A**: 没有硬性限制，但建议：
- 保持在 **100 条以内**以便管理
- 定期清理不再使用的提示词
- 使用标签而不是创建重复的提示词

### Q4: 如何批量删除提示词？
**A**: 当前版本不支持批量操作。替代方案：
- 为待删除的提示词添加"待删除"标签
- 使用标签筛选后逐个删除
- 或直接编辑 `.workbench-data/workbench.json`（需谨慎）

### Q5: 搜索支持正则表达式吗？
**A**: 不支持。搜索是简单的子串匹配：
- 不区分大小写
- 支持空格分隔的多关键词（OR 逻辑）
- 不支持通配符或正则

## 与其他模块协作

### 配合 API Keys 使用
1. 在提示词中引用 API 调用规范
2. 使用 API Keys 模块管理密钥
3. 在 HTTP 客户端中测试 API
4. 根据响应优化提示词

### 配合网址收藏使用
1. 收藏 AI 工具网址（ChatGPT、Claude 等）
2. 点击网址打开工具
3. 从提示词库复制提示词
4. 粘贴到 AI 工具使用

### 配合概述页使用
1. 在概述仪表盘开启"最近使用的提示词"
2. 常用提示词会显示在首页
3. 快速访问高频提示词
