# 网址收藏使用指南

## 功能概述

网址收藏是一个本地化的书签管理工具，支持标题、网址、备注和标签的结构化存储。提供搜索、筛选、快速访问、编辑和删除功能。所有数据按工作区隔离存储，不会上传到云端。

---

## 快速开始

### 第一次使用

首次打开网址收藏时，系统会自动加载 20 条"分页测试网址"示例数据。这些示例使用 `example.com` 域名，主要用于：

- 演示界面布局
- 测试分页功能
- 展示标签系统
- 提供参考格式

你可以：
- 直接删除这些示例
- 修改为真实网址
- 保留作为模板参考

---

### 添加第一个网址

**操作步骤：**

1. 点击页面右上角的"**新建网址**"按钮
2. 填写以下字段：
   - **标题**（必填）：网站名称或用途，例如"Claude AI 官网"
   - **网址**（必填）：完整 URL，必须以 `http://` 或 `https://` 开头
   - **备注**（可选）：补充说明，例如"AI 对话工具"
   - **标签**（可选）：输入标签后按 `Enter` 或逗号添加
3. 点击"**保存**"完成添加

**示例配置：**

| 标题 | 网址 | 备注 | 标签 |
|------|------|------|------|
| Claude AI | https://claude.ai | AI 对话助手 | AI, 工具 |
| GitHub | https://github.com | 代码托管平台 | 开发, Git |
| MDN Web Docs | https://developer.mozilla.org | 前端开发文档 | 文档, 前端 |

## 核心功能

### 1. 添加网址

**字段说明：**

**标题（必填）：**
- 简短描述网站用途
- 建议 5-20 个字
- 例如："ChatGPT 官网"、"阮一峰的博客"

**网址（必填）：**
- 完整的 URL 地址
- 必须以 `http://` 或 `https://` 开头
- 支持子路径和查询参数
- 例如：`https://www.example.com/page?id=123`

**备注（可选）：**
- 补充说明或使用场景
- 不限字数，但建议简洁
- 例如："需要登录"、"免费试用 14 天"

**标签（可选）：**
- 用于分类和筛选
- 按 `Enter` 或输入逗号添加
- 支持中英文和特殊字符
- 建议每个网址 2-4 个标签

---

### 2. 搜索网址

**搜索范围：**
- 网址**标题**
- 网址**URL**
- **备注**内容
- **标签**名称

**使用方法：**
1. 在页面顶部搜索框输入关键词
2. 系统会实时过滤匹配的网址
3. 搜索不区分大小写
4. 清空搜索框显示全部网址

**搜索示例：**
```
输入：github        → 匹配标题或 URL 包含"github"的网址
输入：开发 工具     → 匹配包含"开发"或"工具"的网址
输入：https         → 匹配所有 HTTPS 网址
输入：AI            → 匹配标签或内容包含"AI"的网址
```

---

### 3. 标签筛选

**使用方法：**
1. 点击搜索框右侧的标签按钮
2. 系统会显示当前所有已使用的标签
3. 点击任意标签，筛选带有该标签的网址
4. 再次点击取消筛选

**标签特性：**
- 自动统计：只显示当前工作区中实际使用的标签
- 动态更新：添加或删除网址后，标签列表自动刷新
- 单选筛选：每次只能选择一个标签

**推荐标签体系：**
```
用途分类：工作、学习、娱乐、工具、参考
技术分类：前端、后端、数据库、AI、设计
平台分类：文档、博客、社区、视频、教程
语言分类：中文、英文、日语
```

---

### 4. 打开网址

**方法 1：从列表打开**
1. 找到需要访问的网址
2. 点击行末的"**🔗**"（链接）图标
3. 在新标签页打开网址

**方法 2：点击网址文本**
1. 直接点击网址 URL 文本
2. 在新标签页打开网址

**安全提示：**
- 系统不会验证网址的安全性
- 访问前请确认来源可信
- 避免访问可疑链接

---

### 5. 编辑网址

**操作步骤：**
1. 点击网址行末的"**✏️**"（编辑）按钮
2. 修改标题、网址、备注或标签
3. 点击"**保存**"应用修改

**编辑场景：**
- 网站更换域名
- 补充备注信息
- 调整标签分类
- 修正拼写错误

---

### 6. 删除网址

**操作步骤：**
1. 点击网址行末的"**🗑️**"（删除）按钮
2. 系统会立即删除该网址（**不可恢复**）

⚠️ **注意**：删除操作无法撤销，请谨慎操作。

## 分页浏览

- 每页显示 **6 条**网址
- 超过 6 条时，底部显示分页控制：
  - **◀ 上一页**：跳转到前一页
  - **页码按钮**：直接跳转到指定页
  - **下一页 ▶**：跳转到下一页
- 当前页码会高亮显示
- 搜索或筛选后会重置到第一页

## 数据管理

### 存储位置

网址收藏数据保存在：
```
.workbench-data/workbench.json
```

**存储格式：**
```json
{
  "workspaces": {
    "<workspace-id>": {
      "links": [
        {
          "id": "唯一 ID",
          "title": "标题",
          "url": "网址",
          "note": "备注",
          "tags": ["标签1", "标签2"],
          "createdAt": "创建时间"
        }
      ]
    }
  }
}
```

---

### 备份与导出

**导出工作区配置：**

1. 进入"**设置 > 数据管理**"
2. 点击"**导出工作区配置**"
3. 网址收藏数据包含在导出文件中

**备份建议：**
- 定期备份 `.workbench-data/` 目录
- 导出工作区配置到云盘
- 升级版本前先备份数据

---

### 导入配置

**场景**：迁移到新设备或恢复备份

**操作步骤：**

1. 在新设备的创建工作区页面选择"**导入已有配置**"
2. 或在已有工作区的"**设置 > 数据管理**"选择"**导入配置**"
3. 上传之前导出的 JSON 文件
4. 输入原工作区密码
5. 网址收藏会自动恢复

⚠️ **注意**：
- 导入会与当前网址按标题合并
- 同名网址不会被覆盖
- 新网址会被添加

## 最佳实践

### 1. 命名规范

**好的标题示例：**
- ✅ "Claude AI - 官方网站"
- ✅ "GitHub - chencuy/workbench"
- ✅ "阮一峰 ES6 教程"

**不好的标题示例：**
- ❌ "网站1"
- ❌ "test"
- ❌ "aaa"

**命名建议：**
- 标题简洁明了
- 包含网站/服务名称
- 可选：添加子页面或用途说明
- 避免使用纯数字或无意义字符

---

### 2. 标签策略

**推荐标签层次：**

**第一层（用途）：**
- 工作、学习、娱乐、参考、工具

**第二层（领域）：**
- 前端、后端、设计、AI、数据库、运维

**第三层（类型）：**
- 文档、教程、博客、视频、社区、工具

**第四层（语言）：**
- 中文、英文、日语

**标签使用原则：**
- 每个网址 2-4 个标签
- 标签简洁（2-4 个字）
- 避免同义标签（"前端"和"Frontend"）
- 定期整理和合并标签

---

### 3. 备注规范

**建议包含：**
- 账户信息（如果需要登录）
- 免费/付费说明
- 使用频率（常用/偶尔/备用）
- 特殊注意事项
- 访问限制（需 VPN 等）

**示例备注：**
```
需要登录，账号：user@example.com
免费额度：每月 10GB
常用于代码审查和 PR 管理
需要 VPN 访问
```

---

### 4. 定期维护

**每周维护：**
- 删除失效或不再使用的网址
- 更新变更的 URL
- 补充新发现的有用资源

**每月维护：**
- 检查网址是否仍然有效
- 整理和合并重复标签
- 优化标题和备注
- 导出备份工作区配置

**年度维护：**
- 全面清理无用网址
- 重新规划标签体系
- 评估收藏质量
- 归档历史记录

---

### 5. 与浏览器书签对比

| 特性 | 网址收藏 | 浏览器书签 |
|------|---------|-----------|
| 备注 | ✅ 完整备注 | ❌ 仅标题 |
| 标签 | ✅ 多标签分类 | ❌ 仅文件夹 |
| 搜索 | ✅ 全文搜索 | ⚠️ 仅标题 |
| 跨浏览器 | ✅ 独立存储 | ❌ 需同步 |
| 工作区隔离 | ✅ 完全隔离 | ❌ 全局共享 |
| 数据导出 | ✅ JSON 加密 | ⚠️ HTML 明文 |

**推荐使用场景：**
- **网址收藏**：工作项目、学习资料、需要分类管理
- **浏览器书签**：个人常用网站、临时收藏

## 常见问题

### Q1: 示例网址会被覆盖吗？

**A**: 不会。系统按**标题**合并示例数据：
- 如果标题不存在，添加示例
- 如果标题已存在，保留你的版本
- 不会删除你创建的网址

---

### Q2: 可以导入浏览器书签吗？

**A**: 当前版本不支持直接导入。

**替代方案：**
1. 从浏览器导出书签为 HTML
2. 手动复制粘贴网址到工作台
3. 或使用脚本批量转换（需要编程）

**计划功能：**
- 导入浏览器书签（HTML 格式）
- 导出为浏览器书签
- 与浏览器实时同步

---

### Q3: 可以批量删除网址吗？

**A**: 当前版本不支持批量操作。

**替代方案：**
- 为待删除的网址添加"待删除"标签
- 使用标签筛选后逐个删除
- 或直接编辑 `.workbench-data/workbench.json`（需谨慎）

---

### Q4: 网址数量有限制吗？

**A**: 没有硬性限制，但建议：
- 保持在 **300 条以内**以便管理
- 定期清理不再使用的网址
- 使用标签而不是重复收藏

---

### Q5: 可以收藏本地文件路径吗？

**A**: 技术上可以，但不建议。

**原因：**
- 本地文件路径在浏览器中无法直接打开
- 安全策略限制
- 跨设备无法访问

**替代方案：**
- 使用"应用启动器"模块管理本地快捷方式
- 或使用 `file:///` 协议（部分浏览器支持）

---

### Q6: 搜索支持正则表达式吗？

**A**: 不支持。搜索是简单的子串匹配：
- 不区分大小写
- 支持空格分隔的多关键词（OR 逻辑）
- 不支持通配符或正则

---

### Q7: 可以跨工作区共享网址吗？

**A**: 不能直接共享，但可以通过以下方式：

**方法 1：导出导入**
1. 导出源工作区配置
2. 在目标工作区导入
3. 网址会随配置一起导入

**方法 2：手动复制**
1. 在源工作区查看网址
2. 在目标工作区手动添加

---

### Q8: 可以设置网址图标吗？

**A**: 当前版本不支持自定义图标。

**默认行为：**
- 所有网址使用统一图标（🔗）
- 不会自动获取网站 favicon

**计划功能：**
- 自动获取网站 favicon
- 自定义图标或颜色
- 按分类显示不同图标
