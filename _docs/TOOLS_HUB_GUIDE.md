# 工具箱使用指南

工具箱是个人工作台的统一工具导航中心，将分散的工具入口整合到一个页面中。

## 功能概述

工具箱整合了以下工具：

- **应用启动器** - 启动本机 Windows 应用程序快捷方式
- **番茄钟** - 专注计时工具，支持预设和自定义时长
- **HTTP 测试** - 轻量级 API 测试客户端
- **开发工具** - JSON 格式化、Base64、URL 编码、正则测试、时间戳转换、密码生成
- **文件对比** - 文本文件差异对比工具
- **网络诊断** - Ping 和 DNS 查询工具
- **二维码生成** - 文本转二维码图片
- **系统监控** - 实时显示 CPU、内存、磁盘、网络等系统资源

## 使用方法

1. 点击侧边栏的"工具箱"进入工具导航页面。
2. 工具箱使用网格布局展示所有可用工具，每个工具显示为一张卡片。
3. 卡片上显示工具图标、名称和简短描述。
4. 点击任意工具卡片可跳转到对应的功能页面。
5. 每页显示 6 个工具，超过 6 个后底部显示分页控制。

## 多语言支持

工具箱的界面文字支持三种语言：

- **中文** - 默认语言
- **English** - 英文界面
- **日本語** - 日文界面

语言设置在"设置 > 语言"中切换，工具箱的标题和工具描述会立即更新。

## 设计意图

工具箱的设计目标是简化侧边栏导航结构：

- **整合前**：侧边栏有 8 个独立的工具入口，导航列表较长
- **整合后**：侧边栏只有 1 个"工具箱"入口，所有工具通过工具箱页面访问

这样既保持了所有功能的完整访问能力，又让侧边栏更简洁清晰。

## 技术实现

工具箱使用 React 实现，核心组件位于 `src/main.jsx` 的 `ToolsHub` 组件：

- 使用网格布局（`grid-template-columns: repeat(3, 1fr)`）展示工具卡片
- 支持响应式设计：桌面 3 列、平板 2 列、手机 1 列
- 集成现有的分页组件，每页 6 个工具
- 路由逻辑通过条件渲染实现：`active === 'tools' ? <ToolsHub ... /> : ...`

工具数据结构：

```javascript
const TOOLS = [
  {
    id: 'launcher',
    icon: <Rocket size={20} />,
    nameKey: 'launcher',
    descKey: 'launcherDesc'
  },
  // ... 其他工具
]
```

每个工具包含：
- `id` - 工具的唯一标识，用于路由跳转
- `icon` - 工具图标组件
- `nameKey` - 工具名称在 LANGUAGE_LABELS 中的键
- `descKey` - 工具描述在 LANGUAGE_LABELS 中的键

## 注意事项

- 工具箱只是导航页面，不影响各工具的原有功能
- 所有工具的使用方法、数据保存、配置等都保持不变
- 工具箱页面的分页状态不会持久化，刷新后重置到第一页
